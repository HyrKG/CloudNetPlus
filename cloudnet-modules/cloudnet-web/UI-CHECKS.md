# Web 交互修复与检查记录

日期：2026-10-16。保留现有功能、设计和暂存改动；本轮修改 Web 与入口 REST，不修改核心、Bridge。

## 修复清单

- 停止记录与最新实例快照一起读取、清理；停止事件不再提前解除标记。本地读取实例实际快照，远端沿用全局缓存。前端在服务端接管或实际停止、删除、重新启动前保持停止反馈；明确未提交时恢复操作。
- 任务操作完成后 replace 清除 URL 的 `operation` 参数，保留筛选；结果留在通知中，刷新不重播。失效或无权读取的记录提示一次，网络失败仍可恢复。
- 独立操作结果不互相覆盖；关闭的相同错误不随轮询重弹。弹窗切换保留通知明细展开状态及焦点。
- 弹窗仅在同一次手势于遮罩按下、松开并点击时关闭；数字拖选不会误关。最低数量默认聚焦输入，破坏性确认默认聚焦取消，嵌套弹窗分别响应 Esc。
- 临时启动收到逐实例结果后关闭，部分失败可查看明细；HTTP 失败保留输入。更多菜单统一外部点击、Esc 和选项关闭行为。
- 玩家转服排除正在停止的实例；提交失败保留目标、搜索与选择。
- 控制台重连不抢占编辑焦点，发送时保留命令输入焦点；保留日志回看位置。
- 最低数量输入框统一样式，手机图表提示预留滚动条和边距。

构建时旧 Bridge 的 Nukkit / Velocity / Waterdog 依赖仓库无法解析；使用本地已有 Bridge 编译结果作为依赖，排除其 `compileJava` 后生成 Web、REST。没有新增或替换依赖，也未交付 Bridge。

未运行完整测试套件；真实跨节点停止、双管理员竞争、核心自动补开及生产权限仍需在可连接环境验收。浏览器模拟检查不等同于这些后端验收。

## 更新

已部署此前版本时，只需在入口节点替换同次构建的 `cloudnet-web.jar`、`cloudnet-rest.jar`，重启入口节点并强制刷新浏览器。保留配置、REST 的 `metrics/` 目录及日志。其他节点、核心和 Bridge 无需因本轮修复更新。
